Clase 1

Que el sitio exista

<Archivos y carpetas>

Antes de escribir una sola etiqueta, la carpeta tiene que estar armada. Esto es una fila entera de la rúbrica.

PLAINTEXT
apellido-nombre-diseno-web/
  index.html          <-- la página principal, SIEMPRE con este nombre
  programa.html
  galeria.html
  contacto.html
  css/
    estilos.css       <-- un solo archivo para todo el sitio
  img/
    logo.svg   foto-1.jpg   foto-2.jpg
  docs/
    reglamento.pdf
  video/
    resumen.mp4

Cómo se nombran los archivos

  • Todo en minúscula, sin espacios, sin acentos y sin ñ.
  • Palabras separadas con guion medio: galeria-de-fotos.html
  • La página principal se llama index.html. Siempre.
  • Las mayúsculas importan: para la web, Foto.jpg y foto.jpg son dos archivos distintos.
Así no
Galería De Fotos.html
Foto 1.JPG
Estilos CSS.css
Así sí
galeria-de-fotos.html
foto-1.jpg
estilos.css

<Rutas>

Una ruta es la dirección de un archivo. Hay dos tipos y solo una sirve para un proyecto que se entrega.

Ruta relativa

Parte desde la carpeta del proyecto. Funciona en cualquier computadora, porque la carpeta viaja con el sitio.

img/foto.jpg
css/estilos.css
docs/reglamento.pdf

Ruta absoluta

Parte de la raíz del disco o de internet. Para archivos propios no sirve: en otra computadora esa carpeta no existe.

C:\Users\Ana\Escritorio\foto.jpg
https://www.wikipedia.org

La regla: si en tu código aparece C:\ o /Users/, está mal. Lo único que va con ruta absoluta son los enlaces a sitios de internet.

Subir un nivel

Si un día tenés un archivo dentro de una subcarpeta y necesitás salir de ella, se usan dos puntos:

PLAINTEXT
img/foto.jpg        <!-- entrar a la carpeta img -->
../index.html       <!-- subir un nivel y buscar index.html -->

<La estructura del documento>

Toda página HTML arranca igual. Este bloque se escribe una vez y se copia en cada página nueva.

HTML
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Festival Raíces | Inicio</title>
  <link rel="stylesheet" href="css/estilos.css">
</head>
<body>

  <!-- Todo lo que se VE va acá adentro -->

</body>
</html>
EtiquetaPara qué sirve
<!DOCTYPE html>Le avisa al navegador que el documento es HTML5. No es una etiqueta: es una declaración, y va siempre en la primera línea.
<html lang="es">Envuelve todo el documento. lang declara el idioma del contenido.
<head>La ficha técnica de la página: información sobre el documento. No se ve.
<meta charset="UTF-8">La codificación de caracteres. Sin esto, los acentos y la ñ se ven como símbolos raros.
<title>El texto que aparece en la pestaña del navegador. Distinto en cada página.
<body>La página propiamente dicha: todo lo que se ve.
Síntoma: aparecen Ã¡ o Ã± en vez de acentos → falta el meta charset.

<Texto: títulos, párrafos y listas>

Encabezados

Van de h1 a h6. La jerarquía es semántica, no de tamaño: si un título te parece grande, lo achicás con CSS, nunca bajando de nivel.

HTML
<h1>Festival Raíces</h1>            <!-- uno solo por página -->

  <h2>Qué es el festival</h2>
     <h3>Cómo llegar</h3>
     <h3>Dónde comer</h3>

  <h2>Programa</h2>

Párrafos y listas

HTML
<p>Todo el texto corrido va dentro de una etiqueta p.</p>

<!-- ul: lista SIN orden. Los ítems no tienen secuencia. -->
<ul>
  <li>Tres escenarios con música en vivo</li>
  <li>Feria de discos independientes</li>
</ul>

<!-- ol: lista ORDENADA. El orden importa: pasos, rankings. -->
<ol>
  <li>Tomá el colectivo 57 hasta Parque Central.</li>
  <li>Ingresá por el portón de la calle Belgrano.</li>
</ol>
Recordá: li va siempre dentro de un ul o de un ol. Nunca suelto.

<Imágenes>

img es una etiqueta sin cierre: se abre y se cierra sola. No existe </img>.

HTML
<img src="img/escenario.jpg" alt="Escenario principal iluminado de noche">

<!-- con epígrafe -->
<figure>
  <img src="img/feria.jpg" alt="Puestos con cajas de vinilos">
  <figcaption>Feria de discos, edición 2025</figcaption>
</figure>
AtributoQué hace
srcDónde está la imagen. Siempre ruta relativa.
altQué se ve en la imagen. Lo leen los lectores de pantalla y aparece si la imagen falla. No es opcional.

Qué formato elegir

FormatoCuándoOjo con
.jpgFotografías, muchos colores y degradados.No admite transparencia.
.pngLogos, capturas, cualquier cosa con fondo transparente.Pesa más que un jpg.
.svgLogos e íconos vectoriales.No sirve para fotos.
.gifAnimaciones simples y cortas.Pocos colores. Casi siempre conviene un video.
Antes de subir una foto, redimensionala. Una imagen de 5000 px de ancho hace que la página tarde una eternidad en cargar, y la rúbrica evalúa que no estén pixeladas ni deformadas.

<Etiquetas semánticas>

Las etiquetas semánticas dicen qué papel cumple cada parte de la página. Un sitio hecho todo con div funciona, pero pierde puntos en la rúbrica y es más difícil de leer.

<header> logo y nombre del sitio
<nav> el menú
<main>el contenido propio de esta página, dividido en <section> y <article>
<aside>info secundaria
<footer> tu nombre, la institución y la fecha
HTML
<body>
  <header>
    <img src="img/logo.svg" alt="Logotipo del Festival Raíces">
    <h1>Festival Raíces</h1>
  </header>

  <nav>
    <ul>
      <li><a href="index.html">Inicio</a></li>
      <li><a href="programa.html">Programa</a></li>
    </ul>
  </nav>

  <main>
    <section id="presentacion">
      <h2>Qué es el festival</h2>
      <p>...</p>
    </section>

    <aside>
      <h2>Novedad 2026</h2>
      <p>...</p>
    </aside>
  </main>

  <footer>
    <p>Alumno/a: Nombre y Apellido — noviembre 2026</p>
  </footer>
</body>

La duda de siempre: section, article o div

<section>

Un bloque temático dentro de tu sitio: «Programa», «Contacto», «Cómo llegar».

Ante la duda, section.

<article>

Contenido que se entiende solo, fuera del sitio: una noticia, la ficha de una banda, una receta.

<div>

Una caja neutra que no significa nada. Último recurso, cuando solo necesitás agrupar algo para darle estilo.

En el coloquio: te van a preguntar por qué usaste cada una. La justificación vale tanto como el resultado.

div y span: los divisores neutros

Ninguna de las dos significa nada por sí misma. Se usan cuando hace falta agrupar algo solo para darle estilo y ninguna etiqueta semántica describe ese contenido.

EtiquetaTipoPara qué
<div>De bloque: ocupa todo el ancho y empuja hacia abajo.Agrupar varios elementos en una caja: una galería, una fila de tarjetas.
<span>En línea: se acomoda dentro del renglón de texto.Marcar unas palabras dentro de un párrafo para darles otro color o tamaño.
HTML
<div class="galeria">
  <figure>...</figure>
  <figure>...</figure>
</div>

<p>El festival se hace el <span class="fecha">13 de noviembre</span>.</p>

<Enlaces>

Una sola etiqueta, a, con cuatro usos distintos según lo que pongas en href.

HTML
<!-- 1. Otra página del mismo sitio: ruta relativa -->
<a href="programa.html">Programa</a>

<!-- 2. Un sitio externo: ruta absoluta, y se abre en pestaña nueva -->
<a href="https://www.wikipedia.org" target="_blank" rel="noopener">Wikipedia</a>

<!-- 3. Un documento para descargar -->
<a href="docs/reglamento.pdf" target="_blank" rel="noopener">Reglamento (PDF)</a>

<!-- 4. Un correo electrónico, con el asunto ya cargado -->
<a href="mailto:info@ejemplo.com?subject=Consulta%20desde%20el%20sitio">Escribinos</a>
rel="noopener" acompaña siempre a target="_blank". Evita que la página que se abre pueda manipular la tuya.

mailto con asunto y cuerpo

HTML
<a href="mailto:info@ejemplo.com?subject=Consulta&body=Hola,%20quería%20consultar%20por...">
  Escribir un correo ya redactado
</a>
Los espacios en el asunto y el cuerpo se escriben %20. Si dejás espacios de verdad, algunos navegadores cortan el enlace.

<Anclas>

Un ancla salta a un punto exacto de una página. Hacen falta dos partes: sin las dos, el salto no ocurre.

HTML
<!-- 1) Marcar el DESTINO con un id -->
<section id="horarios">
  <h2>Horarios</h2>
</section>

<!-- 2) Apuntar desde la MISMA página -->
<a href="#horarios">Ir a Horarios</a>

<!-- 3) O desde OTRA página -->
<a href="programa.html#horarios">Ver los horarios</a>
El id es único en cada página: no se repite, no lleva espacios y no empieza con número.
Si el ancla no salta: el id no existe, está repetido, tiene un espacio, o lo escribiste con distintas mayúsculas.

<Tablas>

Las tablas son para datos: horarios, precios, comparaciones. No se usan para maquetar la página.

HTML
<table>
  <caption>Grilla del viernes</caption>

  <tr>
    <th>Horario</th>          <!-- th = celda de ENCABEZADO -->
    <th>Escenario A</th>
    <th>Escenario B</th>
  </tr>

  <tr>                        <!-- tr = una fila -->
    <td>19:00</td>            <!-- td = celda de datos -->
    <td>Las Tardes Largas</td>
    <td>Dúo Sur</td>
  </tr>
</table>

colspan y rowspan

colspan une columnas (a lo ancho). rowspan une filas (a lo alto). Al usarlos hay que recontar las celdas.

HTML
<tr>
  <td rowspan="2">18 a 20</td>   <!-- ocupa DOS filas -->
  <td>Taller</td>
  <td>Marea Baja</td>
</tr>
<tr>
  <!-- solo 2 td: la primera columna ya está ocupada por el rowspan -->
  <td>Taller</td>
  <td>Fósforo</td>
</tr>
<tr>
  <td>22:00</td>
  <td colspan="2">Cierre conjunto</td>   <!-- ocupa DOS columnas -->
</tr>
«Se me desarma la tabla» es casi siempre esto: si una celda ocupa dos columnas, en esa fila va una td menos.
cellpadding y cellspacing son atributos de HTML antiguo. Hoy el espaciado se resuelve con CSS: padding y border-collapse.
Clase 3

Que el sitio se vea

<Cómo se vincula el CSS>

Hay tres formas de aplicar estilos. Para el proyecto, solo la tercera es válida.

No usar

En línea

style="color: red;"

Hay que repetirlo en cada elemento de cada página. Imposible de mantener.

Solo para probar

Interno

<style> ... </style>

Sirve para una sola página. Al tener cuatro, hay que copiarlo cuatro veces.

Esto pide la rúbrica

Externo

<link rel="stylesheet">

Un archivo .css compartido: un cambio, y las cuatro páginas cambian.

HTML
<!-- En el <head> de LAS CUATRO páginas -->
<link rel="stylesheet" href="css/estilos.css">

Anatomía de una regla

CSS
h2 {                                /* SELECTOR: a qué se le aplica */
  color: #7A2E2E;                   /* propiedad: valor;            */
  font-size: 1.5em;
  border-bottom: 2px solid #D9C7A7;
}                                   /* la llave cierra la regla     */
Cada declaración termina en punto y coma. Si falta uno, esa regla y las que siguen dejan de funcionar. Es el error más difícil de encontrar: formateá con Shift + Alt + F y mirá dónde se desarma la indentación.

<Selectores>

Los cuatro selectores del temario.

CSS
/* UNIVERSAL: se aplica a absolutamente todo */
* { margin: 0; padding: 0; box-sizing: border-box; }

/* ETIQUETA: a todos los elementos de ese tipo */
p { line-height: 1.6; }

/* CLASE: lleva punto. Se puede repetir todas las veces que quieras */
.tarjeta { border: 1px solid #ccc; padding: 10px; }

/* ID: lleva almohadilla. Es ÚNICO en la página */
#presentacion { border-top: 5px solid #7A2E2E; }

En el HTML el nombre va sin el punto ni la almohadilla:

Así no
<section class=".tarjeta" id="#presentacion">
Así sí
<section class="tarjeta" id="presentacion">

Clase o id: el DNI y la camiseta

El id es el DNI: uno solo, no se repite. La clase es la camiseta del equipo: la usan todos los que juegan en el mismo equipo. Si algo se va a repetir —tres tarjetas, cinco botones—, es clase.

Nombrá las clases por su función, no por su aspecto: .cabecera y .destacado, nunca .rojo ni .grande. Si mañana cambiás el color, el nombre .rojo queda mintiendo.

<El modelo de caja>

Todo elemento de una página es una caja con cuatro capas. Con estas cuatro palabras se explica casi todo el espaciado.

margin — separación con los elementos de al lado
border — el marco
padding — aire entre el borde y el contenido
content

La foto es el contenido. El paspartú entre la foto y el marco es el padding. El marco es el borde. La distancia hasta el cuadro de al lado es el margen.

CSS
* { box-sizing: border-box; }   /* el padding y el borde quedan DENTRO del ancho */

.tarjeta {
  width: 300px;
  padding: 20px;
  border: 1px solid #ccc;
  margin: 16px;
}

/* Atajos: los valores van en el sentido de las agujas del reloj */
padding: 10px;                  /* los cuatro lados         */
padding: 10px 20px;             /* arriba-abajo | costados  */
padding: 10px 20px 5px 0;       /* arriba derecha abajo izq */
margin: 0 auto centra un elemento que tenga un ancho definido. El auto de los costados reparte el espacio sobrante en partes iguales.

<Pseudo-clases de enlace>

Las cuatro pseudo-clases de enlace. El orden es obligatorio: si lo alterás, hover y active dejan de verse, porque a igual especificidad gana la última regla escrita.

CSS
a:link    { color: #7A2E2E; }                              /* sin visitar        */
a:visited { color: #5C3A5C; }                              /* ya visitado        */
a:hover   { color: #C9A227; text-decoration: underline; }  /* el mouse encima    */
a:active  { color: #000000; }                              /* durante el clic    */
Regla nemotécnica: Link, Visited, Hover, Active — «LoVe HAte».

El menú horizontal

CSS

Centrar el contenido y armar una galería

CSS
main {
  max-width: 960px;          /* no se estira infinito en pantallas grandes */
  margin: 24px auto;         /* centrado                                   */
  padding: 0 16px;
}

.galeria {
  display: flex;
  flex-wrap: wrap;           /* si no entran, bajan de fila */
  gap: 16px;
}

.tarjeta { width: 30%; }
float y clear era el método histórico para poner cosas al costado. Hoy se usa display: flex, que es más simple y no rompe el resto del diseño. Conviene reconocerlos igual: entran en el temario.

Las cuatro propiedades que mueven las cajas

PropiedadQué haceValores del temario
displayCambia el comportamiento de la caja.block · inline · inline-block · flex · none
floatSaca el elemento del flujo y lo pega a un costado; el texto lo rodea.left · right · none
clearImpide que un elemento quede al lado de uno flotado: lo baja.left · right · both
positionCambia cómo se ubica el elemento en la página.static · relative · absolute · fixed
CSS
/* float: el método histórico. Hay que limpiarlo después. */
.foto  { float: left; margin-right: 16px; }
.texto { clear: both; }

/* position */
.caja     { position: relative; }                        /* se corre respecto de su lugar */
.etiqueta { position: absolute; top: 8px; right: 8px; }  /* respecto del padre relative   */
.barra    { position: fixed; bottom: 0; }                /* fija en la pantalla           */
position: absolute se ubica respecto del ancestro más cercano que tenga position: relative. Si ninguno lo tiene, se ubica respecto de la página entera.

Que el sitio responda

<Formularios>

El label es lo que está impreso al lado del renglón; el input es el renglón. El for del label tiene que ser idéntico al id del input.

HTML
<form action="#" method="post">

  <label for="nombre">Nombre y apellido</label>
  <input type="text" id="nombre" name="nombre"
         placeholder="Ej.: Ana Pérez" required maxlength="60">

  <label for="correo">Correo electrónico</label>
  <input type="email" id="correo" name="correo" required>

  <label for="edad">Edad</label>
  <input type="number" id="edad" name="edad" min="16" max="99">

  <label for="area">Área</label>
  <select id="area" name="area" required>
    <option value="">Elegí una opción</option>
    <option value="sonido">Sonido</option>
    <option value="prensa">Prensa y redes</option>
  </select>

  <label for="mensaje">Contanos por qué querés participar</label>
  <textarea id="mensaje" name="mensaje" rows="5" maxlength="500"></textarea>

  <button type="submit">Enviar</button>

</form>

Elegí el tipo de campo según el dato

typePara qué datoRegalo que trae
textTexto corto y libre: un nombre, una ciudad.—
emailCorreo electrónico.El navegador verifica que tenga arroba y dominio.
numberNúmeros: edad, cantidad.Admite min y max.
telTeléfono.En el celular abre el teclado numérico.
dateFechas.Muestra un calendario para elegir.
radioUna sola opción entre varias.Se agrupan con el mismo name.
checkboxVarias opciones a la vez.—

Atributos

AtributoQué hace
nameEl nombre del dato cuando se envía. Sin name, el campo no viaja.
idIdentifica el campo dentro de la página. Es lo que engancha con el for del label.
placeholderTexto de ayuda dentro del campo. No reemplaza al label.
requiredNo deja enviar el formulario si el campo está vacío.
maxlengthLimita la cantidad de caracteres.
Sin un servidor detrás, el formulario no manda los datos a ningún lado. Para este nivel está bien: lo que se evalúa es que esté correctamente construido.
«Hago clic en el texto y no pasa nada» → el for del label no coincide con el id del input.

<Video y audio>

HTML
<video src="video/resumen.mp4" poster="img/portada.jpg" controls width="640">
  Tu navegador no admite la etiqueta video.
</video>

<audio src="video/tema.mp3" controls></audio>
AtributoQué hace
srcLa ruta al archivo. .mp4 para video, .mp3 para audio.
controlsMuestra los botones de reproducción. Sin esto el reproductor es invisible.
posterLa imagen de portada, lo que se ve antes de darle play.

El texto que va entre las etiquetas es el respaldo: solo aparece si el navegador no puede reproducir el archivo.

Etiqueta nativa o YouTube: la rúbrica califica más alto un archivo propio con <video> o <audio> que un iframe de YouTube. El iframe es válido, pero es el plan B.
Ojo con el peso: usá un fragmento de 30 a 60 segundos. Un video largo hace que el .zip no se pueda entregar.

<Responsive>

Un diseño responsive es agua: toma la forma del recipiente. Un diseño con anchos fijos en píxeles es un cubito de hielo: entra o no entra. Son tres ingredientes.

HTML
<!-- 1. En el <head> de LAS CUATRO páginas -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">
CSS
/* 2. Imágenes que nunca desbordan */
img { max-width: 100%; height: auto; }


/* 3. Media queries: SIEMPRE al final del archivo */
@media (max-width: 768px) {
  .tarjeta { width: 45%; }        /* dos por fila */
}

@media (max-width: 480px) {
  .menu ul { flex-direction: column; }   /* el menú se apila */
  .tarjeta { width: 100%; }              /* una por fila     */
  p        { text-align: left; }
}
Una media query es una condición: «si la pantalla mide como máximo 480 px de ancho, aplicá estas reglas». Adentro va CSS común y corriente.
«La página se mueve para los costados» → hay un elemento con ancho fijo más grande que la pantalla. Buscá anchos en px y cambialos por porcentajes o max-width.

Para probarlo: F12 → ícono de dispositivo (arriba a la izquierda del panel) → elegí un modelo de celular y recorré las cuatro páginas.

<Glosario>

Etiqueta
La marca que envuelve el contenido y dice qué es: <p>texto</p>. Casi todas se abren y se cierran.
Atributo
Información extra que va dentro de la etiqueta de apertura: <img src="..." alt="...">.
Anidar
Meter una etiqueta dentro de otra. Se cierran en el orden inverso al que se abrieron.
Indentar
Correr el código hacia la derecha para que se vea qué está adentro de qué. La rúbrica lo evalúa.
Semántica
Que la etiqueta elegida signifique lo que el contenido es, y no solo cómo se ve.
Selector
En CSS, la parte que dice a qué elementos se les aplica la regla.
Propiedad y valor
Lo que se cambia y cuánto: color: #7A2E2E;
Cascada
Si dos reglas chocan, gana la más específica; a igual especificidad, gana la última escrita.
Ruta relativa
La dirección de un archivo tomada desde la carpeta del proyecto: img/foto.jpg.
Responsive
Que el sitio se acomode al ancho de la pantalla en la que se lo mira.
